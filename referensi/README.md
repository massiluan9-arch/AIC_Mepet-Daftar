# Referensi

Regulasi, dokumen teknis, artikel jurnal yang dapat dibagikan, dan daftar pustaka lengkap paper.

```
referensi/
├── regulasi/           POJK 26/2025, POJK 28/2025, SEOJK 24/2017, SEOJK 6/2017, polis standar gempa AAUI
├── dokumen_teknis/     Peta Sumber dan Bahaya Gempa Indonesia 2017 (PuSGeN)
├── jurnal/
│   ├── dikutip/        artikel yang dikutip paper dan boleh dibagikan
│   └── bacaan_pendukung/ artikel berlisensi Creative Commons yang ditelaah tetapi tidak dikutip
└── verifikasi_doi/     metadata Crossref untuk memeriksa DOI daftar pustaka
```
